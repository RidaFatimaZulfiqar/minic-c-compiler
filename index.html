MiniC

A C compiler written from scratch. Type C code, press Run, and see every stage: tokens, syntax tree, x86-64 assembly and the program’s output. Everything runs in your browser.

Ctrl + Enter 

  






Lexer→Parser→Semantic check→Code generator→Assembly


Supports int, functions, recursion, if/else, while, for, && || ! and print(x). Source and docs: github.com/ridafatimazulfiqar/minic-compiler
